Heart Disease Prediction System – Web Application
Overview

This web application is the front-facing interface of the Heart Disease Prediction System. It allows users to interact with the system through a browser, submit their health data, and view prediction results. The application is built using HTML5, CSS3, JavaScript (ES6), and PHP, with MySQL for structured data storage.

#Technology Stack

#Frontend

HTML5 – Page structure
CSS3 – Styling and layout
JavaScript (ES6) – Interactivity and form handling
Bootstrap – Responsive design framework

#Backend

PHP – Server-side processing and database interactions
MySQL – Relational database for storing user and system data
System Flow
User Interaction – User navigates through the UI and fills in forms.
Form Submission – Data is validated using JavaScript.
Server Processing – PHP handles requests, interacts with MySQL, and prepares data for ML prediction.
Results Display – Results are shown to the user along with relevant information.

#How to Run Locally

Install XAMPP (or any local PHP server).
Place the project folder in the htdocs directory.
Import database.sql into MySQL via phpMyAdmin.
Start Apache and MySQL in XAMPP.
Open a browser and go to: http://localhost/neocardio-hospital/
